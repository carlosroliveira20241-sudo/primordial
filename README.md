# Primordial

Mod de Minecraft (Fabric, 26.2) inspirado no Spore: você começa como um peixinho no oceano primordial, caça criaturas, come as Melhorias que elas dropam e vai evoluindo até dominar a terra.

## Compilar e testar

Precisa do JDK 25.

```
gradlew build        # gera o .jar em build/libs
gradlew runClient    # abre o Minecraft com o mod
gradlew runServer    # abre um servidor de teste
```

Para jogar, cada pessoa precisa de: Fabric Loader, Fabric API, GeckoLib e o .jar do Primordial.
